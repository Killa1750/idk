# Unblocked Game Stash

A collection of unblocked games that can be played anywhere, including restricted networks.

## Games

### Available Games
- [2048](#2048)
- [Snake](#snake)
- [Flappy Bird](#flappy-bird)
- [Tetris](#tetris)
- [Breakout](#breakout)

## How to Use

1. Clone or download this repository
2. Open any HTML file in your browser
3. Start playing!

## Game Descriptions

### 2048
A sliding block puzzle game where you combine tiles to reach 2048.

### Snake
The classic snake game - eat food and avoid hitting walls or yourself.

### Flappy Bird
Navigate through pipes by tapping to make the bird flap.

### Tetris
Stack falling blocks to clear rows and score points.

### Breakout
Bounce a ball to break bricks at the top of the screen.

## Installation

No installation required! Just open the HTML files directly in your web browser.
